UKUSA — client demo website

Stack: HTML + CSS + JavaScript only.

Navigation behavior:
- All internal navigation uses explicit section IDs.
- Navigation uses one direct window.scrollTo call per click.
- No GSAP, Lenis, Locomotive Scroll, page transitions, timeouts or duplicate scroll handlers.
- Reveal animations are IntersectionObserver-only and never control navigation.
- Mobile menu has the same direct navigation behavior.

Real imagery:
The site intentionally uses only real UKUSA imagery from public business/listing image sources (Swiggy Dineout, VenueLook and Zomato). No generated/AI images or fabricated venue photography are included. Images are referenced by their original public URLs so the demo stays lightweight.
